# Proyecto: Lista de Tareas

Aplicación web para registrar tareas, indicar fecha límite y categoría.
Incluye:
‑ Botón para cambiar entre modo claro y modo oscuro
‑ Sección que muestra tareas próximas a vencer
‑ Filtros: todas, pendientes, completadas
‑ Funciones para agregar, editar y eliminar tareas
‑ Guarda la información en el navegador

## Tecnologías
‑ HTML
‑ CSS
‑ JavaScript
